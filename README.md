# Bố cục responsive bằng Flexbox

Header, Navigation, Sidebar, Main Content và Footer dùng Flexbox. Desktop hai vùng, <=768px xếp dọc; menu wrap.

## Chạy
Mở index.html trong trình duyệt. Ví dụ cố định kích thước có khung cuộn ở màn hình nhỏ; các bài bố cục có media query.
